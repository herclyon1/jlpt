# 真题原件

**按场次分文件夹存放。** JLPT 每年 7 月、12 月各一场。

```
2021-07/  2021-12/
2022-07/  2022-12/
2023-07/  2023-12/
2024-07/  2024-12/
2025-07/  2025-12/
2026-07/
待分类/     ← 不确定是哪一场的先扔这里，我来分
```

## 传文件

- 手机 App 直接传进对应场次的文件夹
- **不确定场次、或者懒得分** → 一律传 `待分类/`，我会看内容归位
- 传到 `exams/raw/` 根目录的文件，OCR 时会自动归入 `待分类`

文件名不用改，保持原样即可（来源不同、命名混乱都没关系）。

## 每场理想收录

| 类型 | 用途 |
|---|---|
| 真题试卷 | 题目本体，必需 |
| 答案 / 答题卡 | 对分与验证，必需 |
| 听力原文（台本）| 聴解分析的前提，缺了这一科就没法评估 |
| 解析 | 可选，有更好 |

## OCR 输出

`exams/ocr/` 下会生成同样的场次目录结构，文件名与原件一致、扩展名换成 `.txt`。
