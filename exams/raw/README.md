# 真题原件

**按场次分文件夹存放。** JLPT 每年 7 月、12 月各一场。

```
2021-07/  2021-12/
2022-07/  2022-12/
2023-07/  2023-12/
2024-07/  2024-12/
2025-07/  2025-12/
2026-07/
待分类/     ← 不确定是哪一场的先扔这里，我来分
```

## 怎么把文件弄进来

**不要走 GitHub 网页一个个传。** 65 个文件点 65 次，而且 PDF 体积大、仓库会变重。

推荐：**文件 App 全选 → 分享 → AirDrop 到 Mac**（一次操作，落在 `~/Downloads`），然后：

```bash
bash ocr/intake.sh
```

它会自动：按文件名猜场次归位 → 按内容去重 → 全部 OCR → 报告各场次收录情况。

非 iPhone 的话，iCloud Drive、网盘批量下载到 Mac 都一样，然后指定目录：

```bash
bash ocr/intake.sh ~/某个目录
```

## 原件不入库

`exams/raw/` 下的 PDF 和图片**只留在本地**（已加进 .gitignore）——体积大、而且是受版权的真题。
**仓库只存 `exams/ocr/` 里的文本**，那才是后续分析要用的东西。

## 每场理想收录

| 类型 | 用途 |
|---|---|
| 真题试卷 | 题目本体，必需 |
| 答案 / 答题卡 | 对分与验证，必需 |
| 听力原文（台本）| 聴解分析的前提，缺了这一科就没法评估 |
| 解析 | 可选，有更好 |

## OCR 输出

`exams/ocr/` 下会生成同样的场次目录结构，文件名与原件一致、扩展名换成 `.txt`。
