# B 部分：組句★题求解器

## 设计

```
题干 -> prefix + [空1][空2][空3][空4] + suffix，记录 ★ 在第几空
每个碎片 janome 分词 -> 抽 head/tail 的 (词性, 细类, 表层, 活用形, 原形)
24 种排列 × 5 处接缝，逐缝判定：
  (1) 词汇级接続規格表 RIGHT_REQ：51 条 N1 复合辞/形式名詞的「接続」栏
      （ことなく→動詞辞書形、なり、→動詞辞書形、ままに→連体形、ところで→た形、
        ならでは→体言、がゆえに→連体形/体言……），带词边界校验，
      避免「ようやく」被误当成「よう」、「限りある」被误当成「限り」
  (2) 碎片尾部形态覆盖表 LEFT_OVERRIDE：修正 janome 对复合辞的孤立分词误判
      （「ところで/ならでは/がゆえに」孤立分词会被标成接続詞）
  (3) 泛化词性规则：格助詞后不能叠格助詞；連体化「の」后必须是体言；
      形式名詞（名詞·非自立）必须有连体修饰；です/ます 基本形只能结句；
      名詞+動詞 缺格助詞；未然形后必须是助動詞；
      **連体形/終止形后不能直接跟自立動詞**（两个连体节无法直接堆叠）；
      副詞后不能直接跟助詞；連体詞后必须是体言
  (4) 跨碎片呼応硬约束：いくら/どんなに/たとえ → 下一碎片必须含
      ても/たって/からといって/ところで
全部通过 = 合法排列
判定：合法排列 == 1                 -> 确答
      合法排列 > 1 但 ★位碎片编号一致 -> 仍算确答
      合法排列 > 1 且 ★位不一致       -> 多解
      合法排列 == 0                    -> 无解
软打分（名詞+名詞 罚分 / 格助詞+用言 加分 / 連体形+名詞 加分 /
接続助詞+新句 加分 / 副詞+用言 加分）只在多解时排序兜底，不参与确答判定。
```

## B 部分的诚实检讨

1. **确答 0 题**，这是硬指标，没有任何粉饰空间。求解器在 20 道真题上没有一次靠句法把答案钉死。
2. **硬约束没有错杀**：正确答案 100% 落在 ★候选集里（20/20），说明规则集是 sound 的；
   问题在于 not complete —— 它**太弱，不是太严**。
3. **为什么弱？** 逐题看下来，N1 組句题的碎片有一个共同结构特征：
   **多数碎片是「名詞/形容詞起首 + 接続助詞（て/が/ば/たら/のに）收尾」的完整小句**。
   两个以接続助詞结尾的小句谁先谁后，语法不管——句法上任意排列都合法。典型如 2026-07 #39：
   `どれでもいいと思って / 髪を乾かせれば / 安いのを使っていたが / 高性能の…使ってみたら`
   四个碎片全部这个模式，24 种排列全合法，句法学彻底失效。
   同类还有 2025-07 #37、2025-07 #40、2024-12 #38/#39/#40。
4. **有效的约束确实存在，但只够砍掉一半排列**，砍不到唯一。真正有杀伤力的三类是：
   - **suffix 的接続要求**：「なり、」要動詞辞書形、「ままに」要連体形、「も状況は」不能接が/は、
     「のだが」要連体形 —— 这条最有用，因为 suffix 是题目白给的
   - **形式名詞必须有连体修饰**：ことなく / 分には / のか / ことが
   - **連体形不能直接接自立動詞**
   这些平均把 24 砍到 15.0；最好的两题（2025-12 #39、2025-07 #38）砍到 4。
5. **字符 n-gram 语言模型消融**：用 `converted/*読解*.txt` + `*聴解*.txt` 训了一个 4-gram
   字符 LM（**训练语料不含任何問題6 题面**，无泄漏），加权后成绩从 9/20 掉到 5/20。
   语料只有 7 万字符，太小。默认权重 `LM_W = 0.0`，代码保留供日后接大语料。
6. **最终可用的只有软打分兜底**：全 20 题 9/20 = 45%，3 套正式版 8/15 = 53.3%，
   2024-12 回忆版 1/5 = 20%。比 25% 基线高，但必须打折看待：**规则是在这 20 题上迭代调出来的，
   没有真正的留出集**。规则里没有拟合参数（都是手写语法知识），但"写哪些规则"这个选择本身
   受了这 20 题的影响。真实泛化成绩预计在 30-40%。

## 数据缺陷（求解器顺手查出来的）

**2025-07 #36 的 ★ 位置与答案对不上。** 题干是
`宝くじに ＿＿ ＿★＿ ＿＿ ＿＿ 一生買えそうにない`（★在第 2 空），
四个碎片唯一自然的拼法是 `宝くじに + 当たり(3) + でも(2) + しない(1) + 限り(4)`，
第 2 空 = 「でも」= 选项 2，但答案标的是 3（当たり）。
即：**★ 应该在第 1 空，转写时多打了一组下划线**（或答案键错）。建议核对原卷。
其余 19 题的 ★ 位置与答案自洽。

2024-12 另有两处印刷讹误影响拼接：#36 题干 `積も` 缺「り」（应为「積もりこそしなかったが」）、
#38 选项 `思われるがちだが` 应为「思われがちだが」。这也是 2024-12 全部统计单列的原因。

## 这意味着什么

- 「先看空格前是什么形态，排掉接不上的」这条应试口诀，在 N1 这一档**基本不成立**：
  出题方造干扰项时就已经保证四个选项接续全合法，把区分点全部推到语义/语用层。
  这正是 N1 与 N2/N3 的分水岭——N3 的文法题接续排除法有效，N1 是被刻意堵死的。
- 有效的浅层规则只剩三类，而且都是**低频**的：
  1. **て形补助动词白名单**（敬语题）：`〜ていたす` `〜てなさる` 不成立 → 排 2 个，
     再用主语方向（弊社/当社/私ども → 谦让；お客様/先生 → 尊敬）定答。4 卷出现 1 次。
