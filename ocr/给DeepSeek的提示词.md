# 用 DeepSeek 转标准格式：操作指南

## 一、要喂给它什么

OCR 文本在 `exams/ocr/<场次>/` 下。每场用**两个文件**：

| 文件 | 提供什么 |
|---|---|
| `【1】…真题.txt` | 題目、选项、**末尾的答案表** |
| `【1】…答案解析+听力原文.txt` | **听力台本** |

一次处理**一场的一个科目**（言語知識 / 読解 / 聴解），别一次丢一整场——上下文会不够，质量会掉。

## 二、提示词（直接复制）

### 处理「言語知識」时

```
你是日语试卷格式转换员。下面是 JLPT N1 真题的 OCR 文本，请转成指定格式。

【输出格式】行首 # 是标记行，其余是内容：
#卷 2023-07 N1
#科 言語知識
#大題 問題1
#題 1
#干 思わぬ出来事に、周りは＜騒然＞としていた。
#选 1 ぼぜん
#选 2 そぜん
#选 3 ぼうぜん
#选 4 そうぜん
#答 4

【规则】
1. 只输出上述格式，不要任何解释、不要 markdown 代码块。
2. 問題1（漢字読み）：题干里被考察的那个词用 ＜＞ 括起来。原文没有下划线标记，
   你要根据四个选项的读音反推是哪个词。例：选项是 ぼぜん/そぜん/ぼうぜん/そうぜん，
   那么被考的词是「騒然」。
3. 問題4（用法）：#干 只写被考察的那个词本身，四个选项是四个完整句子。
4. 問題6（組句★）：题干里的四个空写成 ＿＿ ＿＿ ＿★＿ ＿＿，★ 的位置照原文。
5. 問題7（文章文法）：先输出文章，格式为
   #文 G7
   （文章正文，空格处写成 【41】【42】…，编号就是题号）
   #文完
   然后每题写 #題 41 @文 G7，#干 那行省略，只写四个选项。
6. 答案在 OCR 文本末尾的答案表里，格式是「問題N / 45番 46番… / 1 3 2 2」，
   番号和答案按顺序对应。OCR 可能把 46番 识成 6番，按顺序推算即可。
7. 日文必须逐字保真。OCR 有丢字（如「潜している」应为「潜伏している」、
   「らかな声」应为「朗らかな声」），你能确认的补上，不确认的原样保留并在
   该行末尾加 〔?〕。
8. 一题都不能漏。問題1-7 共约 44 题，转完自己数一遍。

【OCR 文本】
（粘贴 真题.txt 的内容）
```

### 处理「読解」时

把上面的 `#科` 改成 `読解`，规则 2-5 换成：

```
2. 每篇文章输出为：
   #文 A1
   （正文，保留段落。文末的（注1）… 也照抄）
   #文完
   然后 #題 45 @文 A1
3. 有下線部的题，题干里的下線部用 ＜＞ 括起来。
4. 問題13（情報検索）：表格/通知按行线性化，保留所有数字和条件。
5. 問題8-13 共约 22 题。
```

### 处理「聴解」时

**同时提供两个文件**（真题.txt 的听力段 + 答案解析+听力原文.txt），提示词换成：

```
#科 聴解
每题格式：
#題 1
#文 T1-1
（该题的完整台本：情境句 + 対話 + 設問句）
#文完
#选 1 …
#选 2 …
#选 3 …
#选 4 …
#答 2

规则：
- 選項来自「真题.txt」的听力段（格式是「1.番」后跟四个选项）
- 台本来自「答案解析+听力原文.txt」（男：/女： 的对话）
- 問題3（概要理解）和問題4（即時応答）试卷上不印选项，选项从台本里取
- 問題4 每题只有 3 个选项
- 台本里的「4.2」这类标记是题号（問題4 第2题），不要输出它
- 全卷約 30 题
```

## 三、验证输出（重要）

DeepSeek 转完，存成 `converted/<场次>_<科目>.txt`，然后跑：

```bash
python3 ocr/check_format.py converted/2023-07_言語知識.txt
```

它会检查：题数对不对、每题选项是否齐全、答案是否都有、格式有无语法错。**不通过就把报错贴回给 DeepSeek 让它改。**

## 四、建议顺序

先转**一场的言語知識**，跑检查器确认格式对了，再批量做其余的。第一次一定会有格式偏差，早发现早修提示词。

优先级：**听力 > 言語知識 > 読解**。听力是现在最缺的（只有 3 套完整），而且新数据里有 8 套的台本。
