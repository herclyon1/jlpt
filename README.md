# JLPT N1 真题存档 + 机械化解题可行性研究

本仓库包含两部分：历年 N1 真题的 PDF 存档，以及在此基础上做的一项实证研究——**能不能不靠日语能力、只靠规则和统计做对 JLPT N1**。

## 一、真题存档

历年 N1 真题、答案与听力原文的 PDF 收集，目前四场。文件命名来自不同来源，未作统一。

| 场次 | 收录内容 |
|---|---|
| 2024 年 12 月 | 真题试卷、答题卡（答案）、听力原文 |
| 2025 年 7 月 | 试题、参考答案、听力原文 |
| 2025 年 12 月 | 真题、答案 |
| 2026 年 7 月 | 真题、答案 + 解析 + 听力原文 |

其中 2026 年 7 月一场附带解析，其余各场仅有答案。

`converted/` 下是上述四场的标准格式文本转写，另含 2019 年 7 月与 2021 年 7 月两场的言語知識部分（结构化数据来自 [Nyxicemoon/JLPT-Past-Exam-Questions](https://github.com/Nyxicemoon/JLPT-Past-Exam-Questions)），研究共使用 6 套卷。

## 二、机械化解题可行性研究

### 一句话结论

| | 题/卷（共96） | 原始正确率 |
|---|---|---|
| 纯随机猜测 | 24.7 | 25.7% |
| **本项目全部工具** | **42.0** | **43.8%** |
| 及格线（100/180）所需 | 56 | 约 58% |

**工具净贡献 +17.3 题/卷。缺口 14 题必须由考生自身语言能力提供。**

**JLPT N1 约 44% 可机械化，56% 不可以——不可机械化的部分恰好是"读懂 / 听懂"本身。**

完整研究记录见 **[FINDINGS.md](FINDINGS.md)**。

### 最有实用价值的三个发现

**1. 頻率带押题（p=0.0005）** — 被考过的句型在真实日语中的使用频次中位数为 214 次，从未被考的仅 36 次，差 6 倍。**按维基百科真实频次排序，精练前 30 条句型可覆盖 80% 的实际考点**，逐卷一致（67%–100%）。频率排名完全来自语料、与考卷无关，因此不需要任何真题就能得到备考优先级。

**2. 纯计数模型完胜规则库（在文法题上）** — 一个无神经网络、无训练、仅查频次表的字符 n-gram 模型，在問題2 文脈規定上达到 **69.0%**、問題4 用法 **52.8%**；而精心设计的接续规则库在問題5 上基本等于乱猜——**40 题中 38 题四个选项接续全部合法**。

**3. 三类题的干净分野** — 可推导的（8%）规则赢，约定俗成的（28%）语料赢，需要理解的（54%）两者皆输。

### 工具

- **[JLPT判题机.html](tools/JLPT判题机.html)** — 单文件离线判题机，粘贴卷面即出四档判定
- **[N1文法速判训练器.html](tools/N1文法速判训练器.html)** — 两段式限时速判训练，715 题覆盖 222 条句型
- **[规则卡片.md](tools/规则卡片.md)** — 供人记忆的 10 条规则，每条附实测数据
- **[ocr/](ocr/)** — macOS 原生 OCR 工具，36 页试卷 9.3 秒，零 API 成本

两个 HTML 均为单文件、纯离线、双击即用。

### 目录

```
FINDINGS.md        完整研究记录（含 20+ 条假设的证伪清单）
FORMAT.md          标准卷面格式规范
exams/raw/         真题原件（PDF/图片）← 新卷子传这里
exams/ocr/         OCR 自动输出的文字层
converted/         标准格式转写（判题器的输入）
tools/             成品工具：判题机、速判训练器、规则卡片
ocr/               OCR 工具 + 批处理 + 全自动脚本
engine/            规则引擎源码 + 句型表 + 汉字音训表
solver/            全栈判题器（规则 + BERT + 句子嵌入）
mining/            统计挖掘的脚本与报告
```

### 加新卷子的流程

1. 把 PDF 或图片传到 `exams/raw/`（手机 App 直接上传即可）
2. 回到 Mac 跑一条 `bash ocr/sync.sh`，自动 OCR 并推回 `exams/ocr/`
3. 把 OCR 文本整理成 `FORMAT.md` 规定的标准格式，放进 `converted/`
4. 跑 `solver/solve.py` 或用 `tools/JLPT判题机.html`

详见 [ocr/README.md](ocr/README.md)。
