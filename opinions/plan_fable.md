# 路线2：可量化的传统学习 —— 测量系统设计

所有数字由 /Users/herclyon/JLPT/repo 数据算出（export/*.json 12 场次 1124 题；
言語知識 529 / 読解 250 / 聴解 345，其中聴解問題4 为 127 题三选一，其余全部四选一）。
复算校验：纯蒙 = 24.92 题（言知 11.00 + 読解 5.50 + 聴解 8.42），聴解纯蒙 16.8 分——与已验证事实一致。

## 0. 一个先于一切设计的实测发现：题库与未来考卷的表层重合率 ≈ 0

从 12 场次真题算出：

| 项 | 题库内唯一数 | 跨场次重复 |
|---|---|---|
| 問題5 文法题正解字符串（归一化后） | 120 | **0 个**重复 |
| 問題1/4 汉字目标词 | 72 | **0 个**重复 |
| 問題2/3/6/7 正解词 | 264 | 1 个重复 |
| 問題5 全部选项字符串 | 465 | 14 个（3.0%） |

**结论：N1 从不复用具体考点的表层形式。背会 1124 道题的答案，对下一场考试的直接迁移为零。**
这决定了整个测量系统的骨架：必须区分两种完全不同的"会了"——

- **Tier A（可复测资产项）**：假名读音、词义、文法型、即答定型句。刺激本身就是知识
  （「侮る」读 あなどって，这个事实会原样出现在生活和考场上）。对这类项，
  逐项 SRS 复测是有效测量。库存：文法速判训练器 715 项、即答 127 项（含音频）、
  polarity_list 68 项、詞彙类可再抽 ~330 项。
- **Tier B（一次性探针）**：読解 250 题、聴解問題1/2/3/5 共 218 题、整卷模考 12 场。
  做过一遍就记住了答案，**同一题第二次的正确率不再是测量值，是污染值**。
  这是一台"胶卷有限的测量仪"：読解只有 250 次首曝机会，用一张少一张。

对应到 ML 语言：**Tier A 曲线是 training loss，Tier B 首曝正确率是 validation loss，
考场是 test set。**表层重合率为 0 意味着：只有 validation 指标能预测考试。
任何把刷题正确率（含重刷）当进度的方案都是在报 training loss，必然虚高。

## 1. "会了"的不模糊判据（可由日志自动判定）

### Tier A：单项掌握态（mastered），一个可撤销的状态机

`item 处于 mastered ⇔ 同时满足：`

1. **最近 3 次作答全对**（终身至少 3 次正确）；
2. **最后两次作答间隔 ≥ 7 天**——即该项已在无接触一周后存活。
   等价于现有 N1文法速判训练器 8 级 SRS（IV=[0,0.002,0.02,0.5,2,6,18,50] 天）的 **box ≥ 6**；
3. **每次都在时限内**：詞彙 8 秒、文法 20 秒、即答 = 音频长度 + 5 秒。
   时限依据考场预算：言知+読解共 110 分钟，読解 22 题按 3 分钟/题吃掉 66 分钟，
   剩 44 分钟给 44 道言知题 = 60 秒/题上限，训练时限取其 1/3~1/7 留冗余；
4. **可撤销**：此后任何一次答错或超时 2 倍时限，立即跌回 learning 态。
   "会了"不是里程碑，是需要维持的状态——这正是与硬盘的区别，也是诚实之处。

三个字段（correct, rt_ms, gap_days）即可机判，无任何主观量。

### Tier B：类别收敛（converged），只认首曝

`类别 c 收敛 ⇔ 最近 30 道首曝题的 Wilson 95% 置信下界 ≥ 该类别目标正确率，
且最近 3 个探针窗口的斜率在 ±3pp 内（平台期）。`

类别目标从及格反推（180 分制，及格 100 + 三科各 19 分底线）：

| 科目 | 蒙题基线 | 目标正确率 | 得分 | 依据 |
|---|---|---|---|---|
| 言語知識（1.36分/题） | 25% → 15.0分 | **65%** | 39分 | Tier A 可规模化，最便宜 |
| 読解（2.73分/题） | 25% → 15.0分 | **60%** | 36分 | 单题分值最高 |
| 聴解（2.0分/题） | 28% → 16.8分 | **45%** | 27分 | 底线19分，必须超蒙 |
| 合计 | 46.8分 | | **102分** | 过线 100，留 2 分余量 |

聴解最优先突破口是問題4（11 题/卷，三选一，蒙 33%）：127 个即答音频是 Tier A 性质的
定型句，从 33%→70% 即 +4.0 题 = +8.1 分，单科从 16.8 → 24.9 分，一项就基本解除死刑。

## 2. 进度可视化：三张"人脑训练曲线"

**图1 资产曲线（training 侧）**
横轴：日历天。纵轴：处于 mastered 态的项数，按域堆叠（文法/詞彙/即答），
叠画 lapsed（跌落）细线。收敛判定：mastered 数达目标且周跌落率 < 总量 2%。
形状预期：早期近似线性（斜率 = 习得速率 a 项/小时），后期饱和。

**图2 泛化曲线（validation 侧，预测考试的那条）**
横轴：该科累计学习小时数 H。纵轴：每周首曝探针的正确率，画 Wilson 95% 置信带，
底部画蒙题线（0.25/0.28），顶部画目标线（65/60/45%）。
收敛判定 = 上文 Tier B 判据。**这是唯一等价于 ML validation loss 的图。**

**图3 合格概率时间线（唯一的汇总数字）**
每周用当前各科估计正确率做 10000 次二项抽样（含三科 19 分底线规则），
纵轴 = P(合格)，画中位数 + 80% 带。用户要的"一眼看趋势"就是这条线在爬还是躺平。

**必须诚实标注的噪声底**：周探针 23 题时单点 SE ≈ ±10pp，30 题 ≈ ±9pp，
整卷 44 题言知 ≈ ±7.5pp。所以图2 单点无意义，趋势要 3 点起看——
这不是设计缺陷，是二项分布的物理下限，图上必须画出置信带而不是只画点。

## 3. 对用户质疑的正面回应："你们能研究明白人脑吗"

**他说对的部分（三条，全部成立）：**
1. 我们确实没有大脑的写入接口，无法保证"教了=存进去了"；
2. 我们无法直接观测内部状态，一切都是行为推断；
3. 大脑不是硬盘还有一层他没说破的含义：**读取会改写**——测一次本身就强化记忆
   （testing effect），且**探针会自毁**——読解题测过一遍就报废。硬盘没有这两条。

**"当黑箱做输入-输出测量"的看法：成立，但要打两个补丁。**

成立在哪：心理测量学百年来就是这么干的（IRT 全套都是黑箱 I/O 建模），
且对 Tier A 项，黑箱测量是**逐项精确**的——"背後=はいご 这一项，在 7 天间隔后
仍能 8 秒内正确提取"是一个和单元测试同等硬度的事实，1124 题库对这类项
就是一台可靠的测量仪。更妙的是"读取即写入"在这里是特性不是缺陷：
测量动作本身就是最有效的训练动作（提取练习效应），测量仪兼任写入器。

不成立（需修正）在哪：
1. **"精确知道哪些项进去了"只对 Tier A 为真。**读解/听力是技能不是条目，
   只能测到类别级、±10pp/周、且胶卷有限（読解仅 250 次首曝）。
2. **"进去了"≠"考试能用"。**实测 0/120 文法正解、0/72 汉字词跨场次重复——
   题库内项目掌握度是 training 指标，必须靠首曝探针另测泛化。
   把两者画在同一张图上就会骗自己，这正是用户警惕的"感觉好像能行"。

**诚实结论：路线2 可行，但要把承诺降到测量物理允许的分辨率——
周级、科目级、±10pp；月级趋势 ±5pp。**这比 ML loss 曲线粗（n 小、探针自毁、
且大脑在睡眠中离线巩固，当天测量系统性低估次日状态），但足以支撑
唯一需要它支撑的决策：合格概率在爬还是躺平、该不该重新分配时间。
"不能有模糊的地方"能兑现到这个粒度，再细就是伪精度。

## 4. 预测模型："再练 X 天能到多少题"

**最简可行模型（每科 3 参数饱和指数）：**

```
p_s(H) = c_s − (c_s − g_s) · exp(−H / τ_s)
```
- g_s = 蒙题基线（固定：0.25 / 0.25 / 0.28），c_s = 个人天花板，τ_s = 时间常数，
  H = 该科累计学习小时。前 4 个探针点不够拟合 τ 时，先固定 c=0.85 退化为单参数。
- 预测：E[得分](H) = Σ n_s·pts_s·p_s(H)，P(合格) 用二项蒙特卡洛（含底线规则）。
- Tier A 侧另配一个更糙但更稳的线性模型：mastered(t) ≈ a·(累计练习小时)，
  a 由前两周日志直接算，回答"再练 X 小时 ≈ +aX 项"。

**拟合所需字段**（缺一不可）：每次作答的 ts、item_id、domain、first_exposure、
correct、rt_ms，外加每日学习分钟数（可由 ts 聚合，无需手记）。

**可靠性诚实声明**：周探针 n≈23、SE±10pp，6 个点拟 3 参数 → 置信区间很宽。
该模型第 4~5 周起能可靠区分"仍在上升 vs 已平台"（这是唯一需要的决策信号），
但外推不要超过已观测时长的 1.5~2 倍；"精确到考前第几天达标"的承诺不可靠，
不做。読解胶卷预算也限定了测量总时长：保留 2 场整卷（44 读解题）做考前终检，
剩 206 道首曝按 23 题/周 = **9 周测量窗口**，这就是路线2 的自然工期。

## 5. 落地规格

### 5.1 日志格式：JSONL，一行一次作答（追加写 localStorage，一键导出）

```json
{"ts":"2026-09-01T21:03:11+09:00","tool":"soku","mode":"probe",
 "item":"2024-12-聴解-4-3","domain":"listen","mondai":4,
 "first":true,"correct":false,"picked":1,"answer":3,
 "rt_ms":4210,"gap_d":null,"box_before":0,"box_after":0}
```
- `mode`: drill（训练，可重复）/ probe（首曝探针，只抽未见项）/ mock（整卷模考）。
- `first`: 该 item 终身首次作答。読解トレーナー现在把错题塞回 queue 重做——
  重做必须记 first=false，否则泛化曲线被污染。
- 体积：~150 字节/条，localStorage 5MB ≈ 3 万条作答，足够整个备考期。

### 5.2 三个现有训练器的改造点

| 训练器 | 现状 | 需加 |
|---|---|---|
| N1文法速判训练器 | 已有 8 级 SRS + box 持久化 | 只差 JSONL 导出 + rt 时限判据 |
| 即時応答トレーナー | 仅场内计数，无持久化 | 完整加：逐项状态、SRS、日志 |
| 読解トレーナー | 仅场内计数；错题回炉 | 加 seen 集合、probe 模式（只抽未见）、first 标记 |

### 5.3 进度仪表盘：单文件 HTML（无依赖）

结构四层：
1. **导入层**：`<input type=file>` 读 .jsonl（或直读同域 localStorage）；
2. **计算层**：mastery 状态机（第 1 节判据逐条重放日志）、按类别 Wilson 区间、
   三参数指数拟合（网格搜索 τ、c 各 50 步即可，~30 行 JS，无需库）、
   二项蒙特卡洛 P(合格)；
3. **视图层**：图1 资产堆叠面积、图2 泛化曲线+置信带+蒙题线/目标线、
   图3 合格概率时间线、可排序 item 表（≥4 次错 = leech 高亮）；SVG 手绘即可；
4. **胶卷表**：読解/聴解剩余首曝数倒计时（初始 206/180，扣除 2 场保留卷），
   低于 3 周存量时红色警告——防止把测量仪当练习册挥霍。

### 5.4 节奏

- 每日：Tier A SRS 到期项清零（预计 15~25 分钟；715 文法+127 即答+68 极性 ≈ 910 项，
  按终身 3~5 次复测 × ~15 秒 ≈ 总计 30 小时内摊完）；
- 每周：読解探针 23 题（~70 分钟）+ 聴解探针 20 题；当晚看三张图；
- 第 4/9 周：用保留整卷做模考（干净 test set），校准图3 的预测偏差。

## 结语

用户的质疑是对的，而且比他自己表述的更对（读取会改写、探针会自毁）。
但"造不出写入器"不否定"造得出测量仪"。这套系统对条目级知识给出单元测试级的
硬判据，对技能级知识给出带诚实置信带的周级曲线，对"感觉好像能行"给出的替代品
是一条每周更新的 P(合格) 时间线。它比 ML 的 loss 曲线粗，粗多少、为什么粗、
粗到哪一档为止，全部有数——这就是对"不能有模糊的地方"能兑现的全部，也够用。
